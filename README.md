# Task Manager | Organize Daily Tasks

Task manager with priorities, filters and saved tasks, built with HTML, CSS and JavaScript.

**Live demo:** https://soni200294.github.io/task-manager-web/

## Features
- Add tasks with High, Medium or Low priority
- Mark tasks as done and delete them
- Filter by All, Active or Done
- Remaining task counter
- Tasks saved in the browser (localStorage)
- Safe handling of user input

## Tech Used
HTML, CSS, JavaScript

## How to Run
Open the live demo link, or download the repo and open `index.html` in a browser.
